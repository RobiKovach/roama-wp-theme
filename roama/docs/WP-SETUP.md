# Тема ROAMA: встановлення і що можна змінювати

Класична тема WordPress: та сама розмітка, стилі й скрипти, що й демо-сайт ROAMA. Тексти й картинки
змінюються в адмінці через поля, макет лишається цілим.

## 1. Що потрібно

- WordPress 6.5 або новіший, PHP 8.1 або новіший.
- Плагіни (тема їх не містить, ставляться з «Плагіни → Додати новий»):
  - **Secure Custom Fields** — обов'язково: усі поля вмісту. Без нього сайт показує типовий демо-вміст,
    а адмінка попереджає вгорі екрана.
  - **Contact Form 7** — обов'язково для форми. Без нього секція «Зв'язатися з нами» не показується.
  - **Flamingo** — рекомендовано: копія кожної заявки в адмінці («Flamingo → Вхідні повідомлення»).
  - SEO-плагін — не обов'язково. Тема сама друкує заголовок, опис і картинку для соцмереж із групи
    «SEO сторінки»; коли активний Yoast SEO, Rank Math або The SEO Framework, тема поступається йому.

## 2. Встановлення

1. «Зовнішній вигляд → Теми → Додати нову → Завантажити тему» → файл `roama-theme-ДАТА.zip` → «Встановити» →
   «Активувати».
2. Встановіть і активуйте плагіни з розділу 1.
3. Імпортуйте демо-вміст — один із двох способів:
   - в адмінці: «Зовнішній вигляд → ROAMA: імпорт вмісту» → «Імпортувати вміст»;
   - у терміналі сервера: `wp roama import`.

   Імпорт створює: дві картинки в «Медіафайлах» (з описом для незрячих), сторінки «Головна»
   (стає головною сторінкою сайту), «Про шаблон» (шаблон «Про нас») і «Політика конфіденційності»
   (стає сторінкою політики в «Налаштування → Конфіденційність»), тексти всіх полів, контактну форму,
   меню в шапці й у підвалі, постійні посилання вигляду `/назва-сторінки/`, назву сайту «ROAMA»
   (лише коли в сайту ще стандартна назва WordPress).

   Повторний запуск нічого не дублює і не змінює того, що ви вже заповнили. «Перезаписати»
   (`wp roama import --overwrite`) повертає демо-тексти в усі поля, пункти меню й форму — ваші зміни в них
   буде втрачено. Назви сторінок і їхній текст імпорт ніколи не перезаписує.
4. Впишіть текст політики конфіденційності на сторінці «Політика конфіденційності» замість
   `[FILL IN: …]` (текст дає власник сайту; перевірте його з юристом).
5. Заявки в Telegram і Google-таблицю: `setup/LEADS-SETUP.md`.
6. Іконка сайту: «Зовнішній вигляд → Налаштувати → Ідентичність сайту → Іконка сайту». Поки її немає,
   браузер показує іконку теми.

## 3. Що можна змінювати

| Де в адмінці | Що | Як |
|---|---|---|
| Сторінки → «Головна» | Секції: перший екран, меню «На цій сторінці», картки, текст і картинка до краю екрана, ресурси, плавні розміри, скрол і рух, контакти | Кожна секція — вкладка з перемикачем «Показувати секцію» і полями |
| Сторінки → «Про шаблон» | Заголовок, картинка, довгий текст | Шаблон сторінки «Про нас» |
| Будь-яка сторінка | Заголовок і опис для пошуку, картинка для соцмереж | Група «SEO сторінки» внизу сторінки |
| ROAMA: налаштування | Телефон, email, адреса, соцмережі, текст у підвалі, яка форма CF7 на сайті, опис і картинка для пошуку за замовчуванням | Контакти й соцмережі з'являються в підвалі, коли заповнені |
| Зовнішній вигляд → Меню | «ROAMA: головне меню» (шапка), «ROAMA: меню в підвалі» | Пункти можна додавати, перейменовувати, змінювати порядок |
| Контакт → Контактні форми | Поля і повідомлення форми | Див. `docs/CF7-FORMS.md` |
| Налаштування → Заявки | Telegram-бот і Google-таблиця | Див. `setup/LEADS-SETUP.md` |

Що змінювати не можна (зроблено в темі навмисно): порядок секцій, оформлення, іконки інтерфейсу, якорі
секцій. Секцію, яка не потрібна, вимкніть перемикачем «Показувати секцію»: вона не друкується зовсім, а
меню «На цій сторінці» прибирає посилання на неї.

### Ліміти символів

Кожне текстове поле має жорсткий ліміт: адмінка не дає ввести більше, ліміт написаний у підказці під полем.
Головні:

| Поле | Ліміт |
|---|---|
| Заголовки секцій і сторінок (поля) | 80 |
| Підпис над заголовком, підпис меню якорів | 40 |
| Текст кнопки, посилання меню якорів | 24 |
| Текст першого екрана, текст біля форми | 300 |
| Текст «до краю екрана» | 600 |
| Картки: заголовок / текст | 100 / 220, від 1 до 12 карток |
| Текст сторінки «Про нас» | 8000 (без розмітки) |
| Текст у підвалі | 160 |
| SEO: заголовок / опис | 70 / 160 |

Повний перелік усіх полів з лімітами й підказками — `docs/SCF-FIELDS.md`.

Те, що поля SCF не обмежують, тема обрізає під час збереження: назва сторінки — 80 символів, пункт меню —
40, назва сайту — 60, опис сайту — 160. Довгі пункти меню в шапці переносяться в кілька рядків і не
ламають сторінку; краще 1–2 слова на пункт і не більше 6–7 пунктів.

### Картинки

- Будь-яке співвідношення сторін: картинка обрізається по центру під свою рамку (перший екран 16:9,
  «Про нас» 16:9; картинка до краю екрана заповнює свій блок, найкраще вертикальна 4:5). Головне в кадрі тримайте ближче до центру.
- Завантажуйте від 1600 px завширшки, JPG або WebP до ~500 КБ; WordPress сам робить менші розміри.
- Заповнюйте «Альтернативний текст» картинки в «Медіафайлах» (що на ній зображено); для суто
  декоративної картинки лишайте порожнім.

## 4. Що знати

- Плавний скрол (Lenis) вбудований у `js/roama.js` теми, без сторонніх серверів. Коли в
  системі ввімкнено «менше руху», сайт гортається звичайно і без анімацій.
- Шрифти Onest і Unbounded лежать у темі (`assets/fonts/`, ліцензія OFL), Google Fonts не потрібні.
- Не редагуйте файли теми в адмінці («Редактор файлів теми»): оновлення теми їх перезапише.
