# Поля SCF теми ROAMA

> Згенеровано з `acf-json/` командою `node wordpress/tools/fields-doc.mjs` (у папці `roama/`). Не редагуйте вручну:
> змініть групу полів і запустіть команду ще раз.

Кожна секція головної сторінки і сторінки «Про нас» має перемикач «Показувати секцію» (типово увімкнено).
Текстові поля мають жорсткий ліміт символів: адмінка не дає ввести більше. Порожнє поле заголовка показує типовий
текст теми; порожній необов’язковий текст (підпис, кнопка, пункт меню якорів) не показується зовсім.

Сторінка з шаблоном «Про нас».
